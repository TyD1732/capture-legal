# Support for Capture by TyD

For help with installation, capture behavior, updates, privacy, or deletion:

1. Open an issue at <https://github.com/TyD1732/capture-legal/issues>.
2. Describe the problem and the Capture version shown under Settings > App.
3. Remove usernames, private file paths, webhook URLs, cloud credentials, and private capture content before posting logs or screenshots.

Capture is currently distributed to a private Microsoft Store audience. Access requests must be approved by the publisher and require the email address associated with the recipient's personal Microsoft account.
